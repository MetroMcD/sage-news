        Terminalserver
        Windows Terminal Server / RDS oder Citrix. Sage 100 läuft zentral für mehrere gleichzeitige Benutzer. Telefonie/CTI auf Terminalserver NICHT unterstützt. Microsoft Access muss zwingend in der 32-Bit-Version installiert sein – keine 64-Bit-Office-Komponenten auf dem Rechner erlaubt. Für Dienste mit Sage-ID-Anmeldung (z. B. Webshop, Sage Network, SO Integration) muss auf Windows Server das Microsoft WebView2-Steuerelement installiert und aktiv sein.
        Application-Server
        Sage SData Application-Server. Bei intensiver Nutzung von Control-Center, neuen Dialogen und Reports erhöhen sich die Anforderungen. Pro 1.000 Druckseiten ca. 500 MB temporärer Speicher erforderlich. Microsoft Access muss zwingend in der 32-Bit-Version installiert sein – keine 64-Bit-Office-Komponenten auf dem Rechner erlaubt. Für Dienste mit Sage-ID-Anmeldung (z. B. Webshop, Sage Network, SO Integration) muss auf Windows Server das Microsoft WebView2-Steuerelement installiert und aktiv sein.
        Hardware

          Firewall & Ports (Kap. 4.5)
          Wenn eine Firewall den Internetzugriff einschränkt, müssen auf Clients, Terminalserver und Application-Server die folgenden Ports und Adressen freigegeben sein. Interne Ports als „eingehende Regel“ auf dem jeweiligen Server freigeben; abweichende Ports vorab an den genannten Stellen prüfen.
